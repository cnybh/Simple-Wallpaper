# Simple-Wallpaper

An unobtrusive wallpaper

---

![image](https://github.com/cnybh/Simple-Wallpaper/blob/main/_github%20pages/View.jpg?raw=true)

---

A next-generation smart wallpaper utility that automatically matches your display resolution with natural or cityscape wallpapers, syncs them across the lock screen and desktop, enables one-click switching via the desktop context menu (Shift + right-click for settings), refreshes daily, supports English and Simplified Chinese automatically, and runs on Windows 10/11 with lock-screen sync on Pro editions and above.
